================================================================
TV Gaming Mode для Windows 10
================================================================

Что делает: при входе в Windows автоматически переключает картинку
и звук на телек и запускает Steam Big Picture Mode.

В комплекте:
  - tv-mode.ps1          - основной скрипт (запускается автоматически)
  - pc-mode.ps1          - обратный скрипт
  - hotkey-listener.ps1  - слушатель Ctrl+Alt+P в TV Mode
  - install-task.ps1     - регистрирует автозапуск (запусти 1 раз)


================================================================
УСТАНОВКА - ПЕРВЫЙ РАЗ
================================================================

--- Шаг 1. Скопировать файлы на винду -----------------------------

Создай папку   C:\Tools
Положи в неё четыре .ps1 файла из этой директории.
Итог:
    C:\Tools\tv-mode.ps1
    C:\Tools\pc-mode.ps1
    C:\Tools\hotkey-listener.ps1
    C:\Tools\install-task.ps1


--- Шаг 2. Скачать SoundVolumeView --------------------------------

Это утилита для переключения аудио-устройства из скрипта.
Официальный сайт: https://www.nirsoft.net/utils/sound_volume_view.html
Скачай, распакуй, положи SoundVolumeView.exe в C:\Tools\
Итог:
    C:\Tools\SoundVolumeView.exe


--- Шаг 3. Настроить имена аудио-устройств ------------------------

Открой tv-mode.ps1 в Блокноте (или VS Code) и в блоке НАСТРОЙКИ
укажи кусок имени аудиоустройства ТВ в $TvAudioName и часть имени
дисплея в $TvDisplayName. Если оно не совпадёт, скрипт также ищет
Samsung. Он будет ждать ТВ до $TvDetectTimeoutSeconds секунд,
по умолчанию — две минуты.

Имя дисплея можно посмотреть командой PowerShell:

    Get-CimInstance -Namespace root\wmi -ClassName WmiMonitorID | Where-Object Active | ForEach-Object { $name = -join ($_.UserFriendlyName | Where-Object { $_ -ne 0 } | ForEach-Object { [char]$_ }); $manufacturer = -join ($_.ManufacturerName | Where-Object { $_ -ne 0 } | ForEach-Object { [char]$_ }); "$name $manufacturer" }

Как узнать имя устройства:
  1. Правая кнопка по иконке звука в трее.
  2. "Открыть параметры звука" -> "Панель управления звуком"
     (или сразу нажми Win+R и введи   mmsys.cpl   )
  3. Вкладка "Воспроизведение".
  4. Найди устройство телека (появится когда телек включён
     и ресивер подключён). Скопируй кусок имени, например:
       "Samsung", "TV", "AV Receiver".

То же самое для pc-mode.ps1 - там укажи имя обычных наушников/колонок.

Не обязательно всё имя целиком. Достаточно уникальной части.


--- Шаг 4. Разрешить запуск скриптов PowerShell -------------------

Windows по умолчанию блокирует .ps1 файлы.
Открой PowerShell от имени администратора и выполни:

    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

(это разовое действие, глобально).


--- Шаг 5. Зарегистрировать автозапуск ----------------------------

В том же PowerShell (от админа) выполни:

    powershell.exe -ExecutionPolicy Bypass -File C:\Tools\install-task.ps1

Должно написать "Готово. Задача 'TV Gaming Mode' зарегистрирована."


--- Шаг 6. Проверить ----------------------------------------------

Ручной прогон без перезагрузки:

    powershell.exe -ExecutionPolicy Bypass -File C:\Tools\tv-mode.ps1

Если картинка ушла на телек, звук на телек, Steam открылся
в Big Picture - всё работает. Теперь при следующей перезагрузке
всё случится само.


================================================================
ГОРЯЧАЯ КЛАВИША ДЛЯ ВОЗВРАТА В PC MODE
================================================================

Когда TV Mode запущен, нажми Ctrl+Alt+P. Скрипт вернёт картинку,
звук и план электропитания на компьютер и выйдет из Big Picture, оставив Steam открытым.

Также можно запускать PC Mode ярлыком:

Правый клик на рабочем столе -> "Создать" -> "Ярлык".
В поле расположения вставь:

    powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\Tools\pc-mode.ps1

Название: "PC Mode". Иконку можно поменять (правый клик по ярлыку
-> "Свойства" -> "Сменить значок").


================================================================
ТИПОВЫЕ ПРОБЛЕМЫ
================================================================

* TV Mode не нашёл телевизор -> проверь $TvDisplayName в tv-mode.ps1
  и увеличь $TvDetectTimeoutSeconds, если ТВ долго просыпается.

* Звук не переключился -> проверь что имя $TvAudioName реально
  встречается в списке устройств в mmsys.cpl. Регистр не важен.

* Не запускается при входе -> открой "Планировщик заданий"
  (Пуск -> набери "Планировщик"), в библиотеке найди
  "TV Gaming Mode", правый клик -> "Выполнить". Посмотри
  что пишет.

* Хочешь отключить автозапуск на время -> в планировщике
  правый клик на задаче -> "Отключить".

* Хочешь удалить совсем -> в PowerShell от админа:
      Unregister-ScheduledTask -TaskName "TV Gaming Mode" -Confirm:$false

  /clone     - дублировать
