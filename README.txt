================================================================
TV Gaming Mode для Windows 10
================================================================

Что делает: при входе в Windows автоматически переключает картинку
и звук на телевизор и запускает Steam Big Picture. На время игры изображение
остаётся только на ТВ. Ctrl+Alt+P возвращает рабочий стол на один или два
монитора с прежним основным экраном и расположением.

В комплекте:
  - tv-mode.ps1          - основной скрипт (запускается автоматически)
  - pc-mode.ps1          - обратный скрипт
  - display-mode.ps1     - выбор ТВ и восстановление раскладки мониторов
  - hotkey-listener.ps1  - слушатель Ctrl+Alt+P в TV Mode
  - install-task.ps1     - регистрирует автозапуск (запусти 1 раз)


================================================================
УСТАНОВКА - ПЕРВЫЙ РАЗ
================================================================

--- Шаг 1. Скопировать файлы на винду -----------------------------

Создай папку   C:\Tools
Положи в неё пять .ps1 файлов из этой директории.
Итог:
    C:\Tools\tv-mode.ps1
    C:\Tools\pc-mode.ps1
    C:\Tools\display-mode.ps1
    C:\Tools\hotkey-listener.ps1
    C:\Tools\install-task.ps1


--- Шаг 2. Скачать утилиты NirSoft -------------------------------

SoundVolumeView переключает аудио-устройство:
https://www.nirsoft.net/utils/sound_volume_view.html
Скачай, распакуй, положи SoundVolumeView.exe в C:\Tools\

MultiMonitorTool адресно переключает экраны и сохраняет исходную
конфигурацию мониторов. Она рассчитана на расширенный рабочий стол,
а не на дублирование одного изображения на нескольких экранах:
https://www.nirsoft.net/utils/multi_monitor_tool.html
Скачай, распакуй, положи MultiMonitorTool.exe в C:\Tools\

Итог:
    C:\Tools\SoundVolumeView.exe
    C:\Tools\MultiMonitorTool.exe


--- Шаг 3. Настроить имена устройств ------------------------------

Открой tv-mode.ps1 в Блокноте (или VS Code). В блоке НАСТРОЙКИ
укажи кусок имени аудио-устройства ТВ в $TvAudioName. В начале
display-mode.ps1 укажи уникальную часть Monitor Name в $TvDisplayName.

Чтобы узнать Monitor Name, запусти C:\Tools\MultiMonitorTool.exe
и посмотри колонку Monitor Name у телевизора. Если ресивер показывает
своё имя вместо модели телевизора, используй имя из этой колонки.
Имя должно совпасть только с одним подключённым экраном: при нескольких
совпадениях TV Mode остановится и не изменит конфигурацию дисплеев.

Как узнать имя аудио-устройства:
  1. Правая кнопка по иконке звука в трее.
  2. "Открыть параметры звука" -> "Панель управления звуком"
     (или сразу нажми Win+R и введи   mmsys.cpl   )
  3. Вкладка "Воспроизведение".
  4. Найди устройство телека. Скопируй уникальную часть его имени.

В pc-mode.ps1 укажи имя обычных наушников или колонок.
TV Mode будет ждать телевизор до $TvDetectTimeoutSeconds секунд,
по умолчанию — две минуты.


--- Шаг 4. Разрешить запуск скриптов PowerShell -------------------

Windows по умолчанию блокирует .ps1 файлы.
Открой PowerShell от имени администратора и выполни:

    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

(это разовое действие, глобально).


--- Шаг 5. Зарегистрировать автозапуск ----------------------------

В том же PowerShell (от админа) выполни:

    powershell.exe -ExecutionPolicy Bypass -File C:\Tools\install-task.ps1

Должно написать "Готово. Задача 'TV Gaming Mode' зарегистрирована."


--- Шаг 6. Проверить ----------------------------------------------

Перед запуском открой параметры экрана Windows. Включи только рабочие
мониторы, выбери основной и проверь их расположение. Оставь телевизор
подключённым, но отключи вывод изображения на него. Если используешь
ресивер, включи его и выбери вход ПК.

Запусти TV Mode:

    powershell.exe -ExecutionPolicy Bypass -File C:\Tools\tv-mode.ps1

Проверь, что изображение и звук перешли на ТВ и открылся Big Picture.
Нажми Ctrl+Alt+P. Должны вернуться все рабочие мониторы. Если их два,
проверь основной экран и перемести окно с одного монитора на другой,
чтобы убедиться, что Windows сохранила их расположение.

Запусти PC Mode ещё раз. Рабочие мониторы должны остаться активными:

    powershell.exe -ExecutionPolicy Bypass -File C:\Tools\pc-mode.ps1


================================================================
ГОРЯЧАЯ КЛАВИША ДЛЯ ВОЗВРАТА В PC MODE
================================================================

Когда TV Mode запущен, нажми Ctrl+Alt+P. Скрипт вернёт картинку,
звук и план электропитания на компьютер и выйдет из Big Picture, оставив Steam открытым.

Также можно запускать PC Mode ярлыком:

Правый клик на рабочем столе -> "Создать" -> "Ярлык".
В поле расположения вставь:

    powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\Tools\pc-mode.ps1

Название: "PC Mode". Иконку можно поменять (правый клик по ярлыку
-> "Свойства" -> "Сменить значок").


================================================================
ТИПОВЫЕ ПРОБЛЕМЫ
================================================================

* TV Mode не нашёл телевизор -> проверь, что $TvDisplayName совпадает
  с уникальной частью Monitor Name в MultiMonitorTool. Если телевизор
  долго просыпается, увеличь $TvDetectTimeoutSeconds.

* Найдено несколько экранов с таким именем -> укажи более уникальную
  часть Monitor Name. Пока совпадение неоднозначно, дисплеи не переключаются.

* MultiMonitorTool не найден -> положи MultiMonitorTool.exe в C:\Tools\
  или поправь путь в tv-mode.ps1 и pc-mode.ps1.

* PC Mode не вернул мониторы -> проверь их подключение и повтори запуск
  pc-mode.ps1 из PowerShell командой из шага 6, чтобы увидеть сообщение.

* Звук не переключился -> проверь что имя $TvAudioName реально
  встречается в списке устройств в mmsys.cpl. Регистр не важен.

* Не запускается при входе -> открой "Планировщик заданий"
  (Пуск -> набери "Планировщик"), в библиотеке найди
  "TV Gaming Mode", правый клик -> "Выполнить". Посмотри
  что пишет.

* Хочешь отключить автозапуск на время -> в планировщике
  правый клик на задаче -> "Отключить".

* Хочешь удалить совсем -> в PowerShell от админа:
      Unregister-ScheduledTask -TaskName "TV Gaming Mode" -Confirm:$false
