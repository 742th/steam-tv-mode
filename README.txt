TV Gaming Mode для Windows 10
=============================

При входе в Windows скрипт ждёт выбранный телевизор, переключает изображение
и звук, включает план высокой производительности и открывает Steam Big Picture.
Ctrl+Alt+P возвращает изображение и звук на ПК, восстанавливает исходный план
питания и закрывает Big Picture. Steam остаётся запущенным.

Установка
---------

1. Скопируй tv-mode.ps1, pc-mode.ps1, mode-common.ps1, display-mode.ps1, hotkey-listener.ps1
   и install-task.ps1 в одну постоянную папку, доступную тебе для записи.
   Скачай SoundVolumeView версии 2.45 или новее с сайта NirSoft
   (https://www.nirsoft.net/utils/sound_volume_view.html), распакуй архив.
   MultiMonitorTool (https://www.nirsoft.net/utils/multi_monitor_tool.html) также понадобится.
   Положи MultiMonitorTool.exe и SoundVolumeView.exe рядом со скриптами. На ПК должен быть установлен Steam.

2. Включи телевизор. Проверь, что MultiMonitorTool видит подключённый ТВ.
   Оставь активными только рабочие мониторы в обычном расположении.
   Для двух рабочих мониторов используй расширенный рабочий стол.

3. Открой обычный Windows PowerShell под тем пользователем, который запускает
   Steam. Перейди в папку со скриптами и выполни:

       powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-task.ps1

   Выбери телевизор, затем устройства воспроизведения для ТВ и ПК.
   Установщик сохраняет Monitor ID и оба аудио Item ID в mode-settings.json
   рядом со скриптами. Для установки без диалога передай все три параметра:
   -TvDisplayId, -TvAudioId и -PcAudioId. Повтори установку после переноса
   папки, смены устройств или подключения телевизора к другому порту.

Обновление уже установленной версии
-----------------------------------

При переходе со старой версии после git pull один раз запусти install-task.ps1
из папки, которой пользуется Планировщик заданий. Перезагрузка не требуется.

1. Если сейчас играешь на ТВ, вернись в PC Mode. Оставь рабочие мониторы
   в обычной раскладке, а телевизор — подключённым и включённым.
2. Открой задачу «TV Gaming Mode» в Планировщике. На вкладке «Действия»
   посмотри путь после -File. Если git pull выполнен в этой папке, скрипты
   уже обновлены. Если путь ведёт в другую папку (например, C:\Tools),
   скопируй туда все шесть .ps1 из корня обновлённого репозитория.
   Проверь рядом MultiMonitorTool.exe и SoundVolumeView.exe (версия 2.45
   или новее для SoundVolumeView).
3. В обычном Windows PowerShell под пользователем Steam перейди в эту папку
   и выполни:

       powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-task.ps1

   Выбери телевизор и оба аудиоустройства и дождись сообщения о регистрации задачи.
   Установщик обновит задачу и сохранит выбор устройств. Если старая задача
   создана от администратора и Windows отказывает в доступе при регистрации,
   удали «TV Gaming Mode» в Планировщике с правами администратора, затем
   повтори команду в обычном PowerShell.
4. Выполни проверку ниже: включи TV Mode и вернись на ПК через Ctrl+Alt+P.

Проверка
--------

В папке со скриптами выполни:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tv-mode.ps1

Проверь изображение и звук на ТВ, а также открытие Big Picture. Нажми Ctrl+Alt+P:
должны вернуться изображение, звук и прежний план питания. Проверь запуск TV Mode
ещё раз. Для проверки именно автозапуска выбери «Выполнить» у задачи в Планировщике
или выйди из учётной записи и войди снова.

В любой момент можно вручную запросить PC Mode, включая время ожидания телевизора:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\pc-mode.ps1

Для ярлыка подставь в эту команду полный путь к скрипту в двойных кавычках.
Добавь -WindowStyle Hidden перед -File, чтобы скрыть окно PowerShell.

Диагностика
-----------

Журнал переключений: %LOCALAPPDATA%\steam-tv-mode\mode.log
Посмотреть последние записи в PowerShell:

    Get-Content "$env:LOCALAPPDATA\steam-tv-mode\mode.log" -Encoding UTF8 -Tail 25

* Телевизор не обнаружен: проверь HDMI и включи телевизор. Для повторного
  выбора устройства запусти установщик. Время ожидания задаётся переменной
  $TvDetectTimeoutSeconds в tv-mode.ps1, по умолчанию 120 секунд.
* MultiMonitorTool сохраняет исходное расположение мониторов и основной экран
  в %LOCALAPPDATA%\steam-tv-mode (папка pc-displays со снимком и описанием раскладки).
  Если Windows не смогла восстановить раскладку, оставь оба файла на месте,
  подключи рабочие мониторы и повтори PC Mode.
* Ошибка звука: проверь в SoundVolumeView, что нужное устройство активно,
  его Item ID совпадает с настройкой для режима, а версия утилиты не ниже 2.45.
* Ошибка включения плана питания записывается в журнал, запуск Steam продолжается. Проверь доступные схемы командой powercfg /list.
* Задачу можно временно отключить через Планировщик. Для удаления автозапуска
  выполни в PowerShell после возврата в PC Mode:

      Unregister-ScheduledTask -TaskName "TV Gaming Mode" -Confirm:$false
