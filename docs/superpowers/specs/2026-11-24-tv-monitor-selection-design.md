# Адресное переключение телевизора при нескольких дисплеях

## Цель

В TV Mode показывать изображение только на телевизоре, даже если к ПК подключены два обычных монитора. В PC Mode возвращать конфигурацию экранов, которая была до запуска TV Mode. Один и тот же сценарий должен работать с одним монитором и ТВ, а также с двумя мониторами и ТВ.

## Текущее поведение

`tv-mode.ps1` проверяет через `WmiMonitorID`, что среди активных дисплеев есть имя, совпадающее с `$TvDisplayName` или Samsung, а затем вызывает `DisplaySwitch.exe /external`. Найденный дисплей не передаётся команде: она переключает глобальный режим и не выбирает конкретный экран. `pc-mode.ps1` аналогично вызывает глобальный `/internal`.

## Решение

Использовать MultiMonitorTool от NirSoft для команд адресного управления дисплеями и сохранения/загрузки конфигурации. Утилита остаётся внешней зависимостью, как уже используемый SoundVolumeView; её исполняемый файл не включается в репозиторий. README укажет официальный источник, путь к утилите и способ узнать имя ТВ в её списке.

Официальная документация MultiMonitorTool: https://www.nirsoft.net/utils/multi_monitor_tool.html

## TV Mode

1. Установить и проверить доступность настроенного исполняемого файла MultiMonitorTool. Получить его список дисплеев и искать ТВ по подстроке `$TvDisplayName` в поле `Monitor Name`. Это поле из EDID — источник истины для сопоставления. Если ресивер показывает в Windows собственное или общее имя вместо имени телевизора, указать уникальную часть имени, которую MultiMonitorTool показывает для этого устройства.
2. Сопоставление должно дать ровно один дисплей. Если совпадений нет или их несколько, вывести предупреждение и завершить TV Mode до изменения дисплеев. Не выбирать первый результат и не применять общий fallback по производителю Samsung. Команды переключения адресовать по уникальному `Monitor ID` найденной записи.
3. Если резервной конфигурации ещё нет, сохранить текущую конфигурацию всех дисплеев и список активных `Monitor ID` в `%LOCALAPPDATA%\steam-tv-mode`. Резерв создаётся до изменения экранов. Если резерв уже существует, считать восстановление ожидающим и не перезаписывать его; повторный запуск TV Mode не должен заменить исходную конфигурацию конфигурацией только с ТВ.
4. Включить найденный ТВ, отключить остальные дисплеи и сделать ТВ основным. Проверить, что активен только целевой ТВ. Лишь после успешного перехода продолжить существующее переключение звука, питания и запуск Steam Big Picture.
5. Если включение ТВ, отключение остальных экранов, назначение основного дисплея или проверка результата не удались, загрузить резервную конфигурацию для отката и проверить, что активный список `Monitor ID` совпадает с исходным. Только после успешной проверки удалить резерв. Если откат или проверка не удались, оставить резерв, вывести предупреждение и завершить TV Mode с ошибкой. В обоих случаях не менять звук и план питания и не запускать Steam.

Если MultiMonitorTool отсутствует, телевизор не найден однозначно или не удалось сохранить резерв, не менять конфигурацию дисплеев и завершить TV Mode до остальных настроек. Не вызывать `/external` как запасной вариант.

## PC Mode

Если резервная конфигурация существует, загрузить её через MultiMonitorTool и проверить, что активный список `Monitor ID` совпадает с сохранённым исходным списком. При успешном восстановлении удалить резерв и список активных ID. При ошибке или несовпадении оставить файлы для повторной попытки и вывести предупреждение. Остальные действия PC Mode — звук, план питания и выход из Big Picture — продолжить даже при ошибке восстановления дисплеев.

Если резервной конфигурации нет, сохранить существующий вызов `/internal` как legacy fallback. На ПК с несколькими внешними мониторами он не гарантирует возврат всей обычной конфигурации. Остальные текущие действия PC Mode остаются без изменений.

Резерв означает, что восстановление ещё не подтверждено. Он сохраняется при аварийном завершении скрипта и повторно используется вместо перезаписи. Новый снимок создаётся только после успешного PC Mode, который восстановил и удалил предыдущий резерв.

## Настройка и границы

- Настроенное имя ТВ должно отличать его от остальных дисплеев. README объяснит, как посмотреть `Monitor Name` в MultiMonitorTool и задать уникальную подстроку, в том числе при подключении через ресивер.
- MultiMonitorTool устанавливается отдельно на каждом ПК. Путь к нему настраивается рядом с остальными параметрами скрипта.
- Предполагается расширенный рабочий стол. Документация MultiMonitorTool указывает, что утилита рассчитана на конфигурации с расширенными, а не дублирующими экранами.
- `hotkey-listener.ps1`, аудио-логика, имена аудиоустройств и планировщик задач не меняются.

## Проверка

На Windows проверить вручную:

1. Один монитор и ТВ: TV Mode оставляет включённым только ТВ; PC Mode возвращает монитор.
2. Два монитора и ТВ: TV Mode оставляет только ТВ; PC Mode возвращает оба монитора и их обычное расположение.
3. ТВ за ресивером: имя из MultiMonitorTool сопоставляется с `$TvDisplayName`.
4. Неоднозначное или отсутствующее имя ТВ: конфигурация экранов не меняется, выводится предупреждение, другие настройки TV Mode не применяются.
5. Ошибка на любом шаге перехода в TV Mode: выполняется откат; при ошибке отката резерв сохраняется.
6. Повторный запуск TV Mode не перезаписывает резерв конфигурацией только с ТВ.
7. Ошибка восстановления PC Mode сохраняет резерв для повторной попытки, но остальные действия PC Mode выполняются.

Текущая среда — macOS и не может выполнить Windows PowerShell или MultiMonitorTool; окончательная проверка переключения требует Windows.
